# Roadmap

**Short version:** v0.1.0 records Claude Code + publishes the security-event schema; each version restores a
slice of the shipped `agent-exec-trace` feature set until **v1.0 reaches full shipped-feature parity**.

| Version | Theme |
|---|---|
| v0.1.0 | Record + schema (Claude Code; redaction; local store; OTel export; replay) |
| v0.1.x | Cursor; shadow-agent/MCP inventory |
| v0.2.0 | Instrumentation SDK + analytics pipeline + read API |
| v0.3.0 | 40 detectors + operator UI |
| v1.0 | Full parity (Version Compare, Agent Detail, all Tier-1 + frameworks) |
