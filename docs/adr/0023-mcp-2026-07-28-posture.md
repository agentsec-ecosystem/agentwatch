# ADR-0023 — MCP 2026-07-28 posture

- **Status:** proposed (2026-10-05, v0.2.0)
- **Context:** see [PRD 42](../prd/42-harness-fidelity-and-realtime.md) MCP-1..6 and
  [design/mcp-surface.md](../design/mcp-surface.md). The MCP spec revised: sessions removed from Streamable HTTP;
  Roots/Sampling/Logging deprecated (SEP-2577); MRTR + Tasks added; HTTP+SSE deprecated.
- **Decision:** Migrate the proxy to **Streamable HTTP** (keep HTTP/SSE for legacy, marked deprecated-in-spec);
  record `resources/read`, `prompts/get`, elicitation, and tasks; mark sampling/roots/logging as **closed-by-spec**
  in known-limitations; version conformance fixtures per protocol revision.
- **Consequences:** Full MCP surface coverage and a simpler stateless proxy; protocol-version drift fails CI; the
  sampling gap is retired by the spec, not by us.
