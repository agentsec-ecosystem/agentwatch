# agentwatch v0.1.0 — Execution Plan

**BLUF:** **Port from `agent-exec-trace` first**, then build the security layer. Porting is frontloaded:
M0/M1 port the repo/tooling and schema, M2–M3 port the SDK/redaction, M4–M5 port export/replay and release
tooling. Ship monitor-only.

Status: **draft** — see [WBS](../wbs/v0.1.0/wbs-v0.1.0-index.md) for issue-level work items.

## Porting rule (frontloaded)

Every milestone starts by **porting** its `agent-exec-trace` assets, then adapting/adding. See the
[porting map](../wbs/v0.1.0/wbs-v0.1.0-index.md#porting-map-agent-exec-trace--agentwatch).

## Dependency graph

```
M0 foundation ─► M1 schema ─► M2 adapter+daemon ─► M3 store+redaction ─► M4 export+replay ─► M5 first-run+release
   (port tooling)  (port schema)  (port SDK)          (port privacy/redaction) (port export/replay)  (port CI/release)
```

## Standard exit gate (every milestone)

- [ ] All tests pass · coverage ≥ 95% · lint strict clean (`ruff` zero, `mypy --strict`)
- [ ] **Design docs updated** (milestone-specific list in the WBS)
- [ ] **Port tasks complete** (frontloaded; ported tests pass)

## Per-milestone gates

- **M0** — `make setup`/`lint`/`test` work; `agentwatch --help`; bad config fails closed (F7); CI green.
- **M1** — record + event schemas validate; round-trip green; invalid rejected (F8).
- **M2** — one Claude Code session records end-to-end; ported SDK/LangGraph tests + conformance fixtures green; F2 green.
- **M3** — `verify-store` clean; redaction attack pack 0 leaks; store-full fails closed (F3); chain break surfaced (F4).
- **M4** — OTLP loads in Phoenix + Jaeger; export blocked until self-test (F6); export failure loses no data (F5); replay fidelity green.
- **M5** — clean-machine install ≤15 min; `/healthz` reports `recording`; all F1–F10 green.

## Final release gate

- [ ] M0–M5 exit criteria satisfied (incl. port tasks + design docs)
- [ ] R1–R8 acceptance criteria demonstrated
- [ ] Replay matches transcript; attack pack 0 leaks; fresh-machine ≤15 min
- [ ] Field test + security audit + release notes + compatibility table published
- [ ] OWASP LLM Top-10 coverage matrix published ([PRD 18](../prd/18-security-compliance.md))
- [ ] SBOM + signed artifacts; Scorecard grade recorded

## Sequencing rationale

1. **Port before rewrite** — the shipped project's code is the parity baseline (PRD 10); reusing it is faster and safer.
2. **Schema before adapter** — the trace contract is frozen first (the AgentObservatory lesson).
3. **Redaction before export** — never persist or export secrets (DD-06/09).
4. **First-run before field test** — you can't field-test what you can't install.
