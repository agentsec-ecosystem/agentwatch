# agentwatch v0.1.0 — Execution Plan

**BLUF:** Build the recording path first (R1–R2), then the schema (R5), then export/replay, then the field
test. Ship monitor-only. Each phase has an exit gate; later phases depend on earlier ones.

Status: **draft** — see [WBS](../wbs/v0.1.0/wbs-v0.1.0-index.md) for issue-level work items.

## Dependency graph

```
M0 foundation ──► M1 schema ──► M2 record + store + redaction ──► M3 export + replay ──► M4 first-run ──► M5 release
```

## Phases & exit gates

| Phase | Milestone | Exit gate |
|---|---|---|
| 1. Foundation | M0 | `make setup` works; CLI skeleton; CI green |
| 2. Record + schema | M1 | schema round-trip; security-event schema published |
| 3. Claude Code adapter + store + redaction | M2 | records stored; chain clean; attack pack 0 leaks |
| 4. Export + replay | M3 | OTLP loads in ≥2 backends; replay matches transcript |
| 5. First-run UX | M4 | fresh machine ≤15 min; `/healthz` + `status` |
| 6. Field test + release | M5 | all P0 met; security audit; release notes; tag |

## Per-part exit gates

- **M0** — ruff/mypy/tests green; coverage >90%; CLI `--help` works.
- **M1** — record + security-event schemas validate; versioning policy in tests.
- **M2** — one Claude Code session recorded end-to-end; `verify-store` clean; redaction attack pack 0 leaks; F1/F3/F4/F7 fault tests green.
- **M3** — traces in Phoenix + Jaeger unmodified; replay fidelity test green; F5/F6 fault tests green.
- **M4** — clean-machine install (≤15 min, zero code changes); `/healthz` reports `recording`.
- **M5** — field test report; security audit; compatibility table; SBOM; signed artifacts; tag v0.1.0.

## Final release gate

- [ ] All P0 (R1–R8) met with acceptance criteria.
- [ ] Replay matches raw transcript (automated).
- [ ] Attack pack finds zero secrets in stored records.
- [ ] Fresh machine → first recorded call ≤15 min.
- [ ] Field test report + release notes + security audit published.
- [ ] OWASP LLM Top-10 coverage matrix published ([PRD 18](../prd/18-security-compliance.md)).
- [ ] SBOM + signed artifacts; Scorecard grade recorded.

## Sequencing rationale

1. Schema before adapter (the AgentObservatory "trace contract before detector catalog" lesson).
2. Redaction before export (DD-06/09; never persist or export secrets).
3. First-run UX before field test (you can't field-test what you can't install).
