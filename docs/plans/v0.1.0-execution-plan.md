# agentwatch v0.1.0 — Execution Plan

**BLUF:** The execution **strategy** for v0.1.0 — porting rule and sequencing. The **milestones, work items,
and exit gates live in the WBS** (single source of truth); this file does not restate them.

## Porting rule (frontloaded)

Every milestone starts by **porting** its `agent-exec-trace` assets, then adapting/adding. See the
[porting map](../wbs/v0.1.0/wbs-v0.1.0-index.md#porting-map-agent-exec-trace--agentwatch).

## Sequencing rationale

1. **Port before rewrite** — the shipped project's code is the parity baseline ([PRD 10](../prd/10-feature-parity.md)); reuse is faster and safer.
2. **Schema before adapter** — freeze the trace contract first (the AgentObservatory lesson).
3. **Redaction before export** — never persist or export secrets (DD-06/09).
4. **First-run before field test** — you can't field-test what you can't install.
