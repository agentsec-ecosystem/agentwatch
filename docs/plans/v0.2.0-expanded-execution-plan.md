## 3. Sequencing
1. **DEP-3** (measure end-to-end hook cost) + **managed-policy check (DEP-1)** — cheap; may reshape other designs.
2. **APV + CCO together** in M26 (APV is only authoritative with native telemetry).
3. **LUI-2 in M26, LUI-1 in M27**; **CAP-1/2 + HLD-1 + ACC-1 in M27**.
4. **PRV-3 → PRV-1 → PRV-2**, plus **ENV/MEM/VFY + ACC-2** in M28; **ASI-1 early**; **AGI/POL/FWK in M28**.
5. **OUT/RUN/DEMO/NTF/SBX/IR/CNC/RED/STD** in v0.2.x. `EXT-*` lands with its owning feature.

## 4. Cut-line
- **Defer to v0.2.x:** PG-1..3 (already first to slip; LUI-2 is the general query tier), SYS-1, A2A-2 depth, COR-2..4, TSS-1 depth.
- **Cap for v0.2.0:** LOG-1 at Codex + one more; GWY/CCA stay (cheap, reused by CCO cost stamp).
- **Keep as watch item:** ACS-1 (POL-1 `acs` target is a thin consumer).
