# PRD 07 — Success Metrics

**BLUF:** Success is durable recording and fast forensics — not installs.

## Outcome metrics

| Metric | Target |
|---|---|
| Installs still recording after 30 days ("kept it on") | >70% |
| Time to answer "what did that agent do?" from a standard backend | <5 min |
| Security-event schema adopted by ≥1 non-ecosystem tool | within 12 months |
| Secret leaks in stored records (attack pack) | 0 |
| Fresh machine → first recorded call | ≤15 min |
