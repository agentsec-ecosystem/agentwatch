# PRD 40 — v0.2.0 Program (Best-in-Class Record Layer)

**BLUF:** v0.1.0 shipped the record layer — local-first, hash-chained, redacted, replayable, evidence-capable,
standards-mapped. v0.2.0 makes it **the** record layer: first-mover interop with the IETF Agent Audit Trail,
full OTel GenAI agent-span conformance, real harness fidelity (no more "modeled"), streaming ingestion, honest
detector effectiveness, agent identity/non-repudiation, and one-command compliance reporting — every capability
keeping the v0.1.0 guardrails. The **v0.2.0-expanded** program (PRD 49–59) adds authorization/oversight provenance,
enterprise deployability and recorder attestation, harness-native telemetry, capability supply chain, code provenance,
a zero-Docker local console, agent-facing interfaces, policy-from-history, governance/retention integrity, OWASP
Agentic coverage, and investigation depth. The record remains the sole source of truth throughout.

**Status:** shipped in v0.2.0 (2026-10-08) — originally proposed (2026-10-05); **v0.2.0-expanded** (2026-10-05, PRD 49–59) · **Parent:** agentsec-ecosystem #209 ·
**Supersedes scope:** none (additive) · **Inputs:** v0.1.0 docs (PRD 00–39), `reference/known-limitations.md`, the
generated compatibility matrix, and Sept–Oct 2026 industry research (see §Sources and
`reference/v0.2.0-research-sources.md` §11–§19 for the expanded sources).

> Cross-cutting rules (PRD 19–30): fail closed and never silent (PRD 17); redaction before storage (DD-06);
> the trust boundary stays deterministic — no LLM in redaction, validation, or chain verification; monitor-only,
> every hook exits 0 (R2); local-first, no egress without explicit opt-in (R6); no new runtime dependency
> without a recorded decision (NFR-5); conformance and quality gates apply (NFR-11).

## 1. Why v0.2.0

v0.1.0 shipped a superset of the predecessor and proved it (`release/v0.1.0/`). The released
[known-limitations](../reference/known-limitations.md) and the compatibility matrix name the honest gaps, and
the industry moved in five directions the v0.1.0 PRDs could not anticipate:

1. **The IETF Agent Audit Trail draft** (`draft-sharif-agent-audit-trail-06`) standardized exactly the record we
   already produce, and EU AI Act Art. 12(2) now requires logs that "conform to recognized standards" (application
   staged to Dec 2027 / Aug 2028 by Reg. 2026/1744).
2. **OTel GenAI semconv split into its own repository** with first-class *agent* spans — we pin 1.29.0 while major
   backends ingest 1.37+.
3. **MCP revised to 2026-07-28** — sessions removed, Roots/Sampling/Logging deprecated, Tasks + MRTR added,
   HTTP+SSE deprecated; our proxy speaks the deprecated transport.
4. **Agent identity became a named national priority** (NIST/CAISI AASI, NCCoE, IETF AIMS/WIMSE) and the #1
   stated governance gap.
5. **Big clouds shipped generic agent observability** (AWS CloudWatch Omni, Snowflake Observe, Microsoft ISOC)
   validating the category while leaving the tamper-evident/open-evidence/local-first gaps to us.

## 2. What "best in class" means

| # | Property | v0.1.0 | v0.2.0 target |
|---|---|---|---|
| 1 | Standards-native, not standards-mapped | maps into OTel/OCSF | emits/consumes AAT + OTel agent spans directly |
| 2 | Real-time | ~30 s batch | streaming, ≤1 s hook→view p99 |
| 3 | Attribution-complete | approval provenance only | + agent identity + delegation chain + distributed trace |
| 4 | Tamper-evident by construction | chain + checkpoints | + signed default posture, verified everywhere |
| 5 | Detector-honest | 43 detectors (28 silent) | published precision/recall vs public corpus |
| 6 | Compliance-generating | docs mapping | one-command framework reports, offline-verifiable |
| 7 | Fidelity-declared | "modeled" rows | live/fixture-verified tiers, real captures |

Out of scope by design (PRD 14, unchanged): enforcement (agentpolicy), attack/eval frameworks (agentdrill),
injection classification as a security boundary, hosted SIEM, prompt analytics, silent telemetry, proprietary
formats.

## 5. Release gate (v0.2.0)

1. `export-session --format aat` validates against published AAT fixtures; a third-party AAT consumer round-trips
   it (CUJ-15).
2. `known-limitations.md` shrinks — G1/G2/G4/G7/G8 leave with their proving test (G3/G5/G9 partially).
3. Compatibility matrix has no "modeled" Tier-1 rows; every row carries a `live-verified | fixture-verified`
   tier (PRD 47).
4. Detector precision/recall published against a versioned public corpus; ≥80% of rule detectors non-silent.
5. `compliance report --framework eu-ai-act-art12` runs offline, citing only bundle-verifiable evidence (CUJ-18).
6. Streaming p99 hook→operator-view ≤ 1 s.
7. Agent identity + approval provenance answerable in one command across a multi-agent trace (CUJ-14/16).
8. Field-test report published with the release (FLD-1); claims ledger green.

**v0.2.0-expanded release-gate additions (PRD 49–59):**
9. Clean-machine timing published for macOS, Linux, Windows (closes R2 "partial").
10. Two OTel backends proven (closes R4 "partial").
11. No Claude Code call under auto/bypass reported as `user`; `approval` v2 live (CUJ-21).
12. `agentwatch ui` demonstrated from a clean install with no Docker (CUJ-24).
13. Managed-policy install verified on a real managed config, or declared unverified (CUJ-25).
14. Plugin4Shell-shape capability drift detected (CUJ-23); commit resolves to a session; Agent Trace export validates (CUJ-22).
15. `suggest-policy`/`what-if` write nothing outside `--out`; `owasp-asi-2026` every row runs (CUJ-27, CUJ-18 ext.).
16. Held records survive retention, purge, and index rebuild (CUJ-32).
