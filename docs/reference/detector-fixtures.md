# Reference — Detector fixture provenance

**BLUF:** Standing practice for the public detector corpus (COR-4): every benchmark-sourced fixture is
**shape-synthesized** and **cites a public source**; no external corpus content is copied. This page is the
citation registry and the per-addition changelog.

The corpus itself is `schema/vectors/detectors/detector-corpus-v1.json` (`agentwatch.detector-corpus/1`),
generated by `scripts/generate_detector_corpus.py`; each case carries a `source` tag and a BMWG
`dimension`. See [detector-evaluation](../design/detector-evaluation.md).

## Source registry

Every non-derived `source` tag maps to a public source. `field-test-scenarios` and `benign-traffic` are
agentwatch-authored (no external source).

| Source tag | Public source |
|---|---|
| `agentdojo-shape` | AgentDojo — arXiv:2406.13352 |
| `injecagent-shape` | InjecAgent — arXiv:2403.02691 |
| `asb-shape` | Agent Security Bench (ASB) — arXiv:2410.02644 |
| `atbench-codex-shape` | ATBench / ATBench-Codex — agent-threat benchmark suite |

Vocabulary alignment: IETF BMWG `draft-han-bmwg-agent-security-benchmark` agent-security-benchmark draft (see
[v0.2.0 research sources](v0.2.0-research-sources.md) §"Benchmark/incident sources").

## Governance rules

- **Shape-synthesized only.** Cases reproduce the *shape* of a public trajectory (tool-call sequence, span
  tree, detector expectation), never its content.
- **No secrets/PII.** `services/analytics/tests/test_detector_corpus.py` scans the manifest for secret/PII
  patterns and fails on a match.
- **Cited per fixture.** A benchmark `source` tag with no row above fails `test_fixture_provenance.py`.
- **Versioned.** The corpus version is pinned in every published number; a new release fails stale numbers
  (drift discipline).
