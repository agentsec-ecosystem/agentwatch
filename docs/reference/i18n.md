# Reference — Internationalization & Locale

**BLUF:** v0.1.0 is English-first with UTC timestamps; full i18n is deferred. Stated, not implicit.

## v0.1.0

- **Timestamps:** UTC (ISO 8601) in records and logs; the CLI displays local time with a UTC annotation.
- **Language:** English (UI, docs, logs).
- **Formats:** ISO dates; SI units; USD for cost.

## Deferred (post-v1.0)

- UI localization (i18n framework + translations).
- Locale-aware number/date formatting.
- Non-English docs.

## Principle

Records are locale-independent (UTC, ISO) so they're portable; display is local-optional.
