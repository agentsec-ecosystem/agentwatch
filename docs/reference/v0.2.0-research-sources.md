## 1. Standards & interop (→ PRD 41, design/aat-mapping, design/otel-mapping, design/mcp-surface)

### IETF Agent Audit Trail
- `draft-sharif-agent-audit-trail` (Standards Track): revisions `-01` (Aug 2026) → `-04` (Sept 15 2026) → `-06`
  (Sept 29 2026); expiry ~Apr 2027. datatracker.ietf.org.
- Maps to: EU AI Act Reg. 2024/1689 Art. 12; SOC 2 TSC; ISO/IEC 42001; draft **ISO/IEC 24970**; draft
  **prEN 18229-1**; **PCI DSS v4.0.1** (Req. 10.3/10.5/10.7).
- Key clauses cited: pre-execution recording (a `denied` decision MUST be `record_phase: pre_execution`); action
  taxonomy `tool_call`/`tool_response` (`response_hash`, `response_size`)/decision/lifecycle; content fingerprint
  (SHA-256 pre-redaction); retention §9 (12 mo high-risk / 6 mo general).

### OpenTelemetry GenAI semconv
- Moved from `open-telemetry/semantic-conventions` to **`open-telemetry/semantic-conventions-genai`** (registry:
  `gen_ai.*`, `mcp.*`, `openai.*`).
- agentwatch pin: **1.29.0**; Datadog ingests GenAI semconv **1.37+**.
- Agent spans (status `Development`): `create_agent`, `invoke_agent` (client/internal), `invoke_workflow`, `plan`,
  `execute_tool`, skills (`load skill`, `read skill resource`), command execution.
- Attributes: `gen_ai.operation.name`, `gen_ai.provider.name`, `gen_ai.agent.id/name/version`,
  `gen_ai.conversation.id`, `gen_ai.tool.definitions`.
- Sources: opentelemetry.io/docs/specs/semconv/gen-ai; OTel blog "AI Agent Observability" (2025) and "Inside the
  LLM Call: GenAI Observability" (2026); `open-telemetry/semantic-conventions-genai` docs.

### Model Context Protocol
- Spec revisions: `2024-11-05` (legacy), `2025-03-26`, `2025-06-18`, `2025-11-25`, **`2026-07-28`** (latest).
- 2026-07-28 SEPs: SEP-2567 (sessions removed), SEP-2663 (tasks redesign), SEP-2106 (schema 2020-12),
  SEP-837 (DCR `application_type`), **SEP-2577 (Roots/Sampling/Logging deprecated)**, SEP-2596 (HTTP+SSE
  deprecated, includeContext values deprecated).
- 2025-11-25: OIDC discovery, icons, incremental scope consent, URL-mode elicitation, sampling tool-calling,
  OAuth Client ID Metadata Documents, experimental tasks.
- 2025-06-18: JSON-RPC batching removed, structured tool output, OAuth Resource Server classification, RFC 8707
  resource indicators, elicitation, resource links.
- Source: modelcontextprotocol.io/specification changelogs.

### EU AI Act
- Regulation (EU) 2024/1689, Art. 12 (record-keeping) + Art. 19 (logs) + Art. 26 (deployer duty); Art. 12(2)
  "conform to recognized standards or common specifications"; Art. 14(5), 72, 79(1).
- Staging: **Regulation (EU) 2026/1744** (Digital Omnibus) → **2 Dec 2027** (Annex III), **2 Aug 2028** (regulated
  products).
- Sources: artificialintelligenceact.eu; euaiact.com; ai-act-service-desk.ec.europa.eu; EUR-Lex.

### NIST / CSA
- **CAISI AI Agent Standards Initiative** (Feb 17 2026): interoperability, security, open protocols.
- **NIST IR 8596** Cyber AI Profile (preliminary draft, Dec 2025).
- **NCCoE** concept paper "Accelerating the Adoption of Software and AI Agent Identity and Authorization"
  (Feb 5 2026; comment through Apr 2 2026); companion NCCoE project; MCP listed as a considered protocol
  (OAuth/OIDC delegation).
- **CSA** research notes (Mar–Apr 2026): 79% of orgs run agents; ~1 in 5 can interrupt; >75% lack agent-identity
  policies; NIST frames multi-agent **non-repudiation** as foundational.
- Sources: nist.gov news; nccoe.nist.gov PDFs; labs.cloudsecurityalliance.org notes.

## 3. Agent identity (→ design/agent-identity, PRD 44)

- **IETF AIMS** `draft-klrc-aiagent-auth-00` (Mar 2 2026): WIMSE + SPIFFE/SPIRE + OAuth 2.0; identifier WIMSE URI;
  credentials X.509-SVID / JWT-SVID / WIT.
- **WIMSE for agents** `draft-ni-wimse-ai-agent-identity-01` (Oct 20 2025): delegation binding to human-owner.
- **OpenID Foundation** "Identity Management for Agentic AI" (Oct 2025); candidate standards OAuth 2.0/2.1, OIDC,
  SPIFFE/SPIRE, SCIM.
- **Google Cloud Agent Identity** (2026): `spiffe://trust-domain/resources/...`; 24 h X.509 rotation;
  certificate-bound tokens; docs.cloud.google.com/iam/docs/agent-identity-overview.
- **HashiCorp Vault 1.21+**: native SPIFFE auth for non-human identities (hashicorp.com blog).
- **Red Hat kagenti** (Jun 10 2026): SPIFFE mTLS + RFC 8693 token exchange ("on behalf of") + agent lifecycle
  policy (next.redhat.com).
- **NCCoE** workstreams: Identification, Access Delegation, Logging and Transparency, prompt/data-flow provenance.
- Statistics: **97%** NHIs over-privileged (Entro Security); **90%** agents over-permissioned (Obsidian
  Security); **>75%** orgs lack AI-identity policy and ~1 in 5 can interrupt (CSA); **37%** of CISOs rank AI
  security #1 (Gartner, via Exabeam).
- Paper: `arxiv 2604.23280` "AI Identity: Standards, Gaps, and Research Directions for AI Agents".
