# Tutorial 06 — Replay & Investigate

**BLUF:** Answer "why did this agent do that?" from a recorded session.

1. `agentwatch sessions` → pick the session.
2. `agentwatch replay <id>` → ordered timeline (spans, outcomes, anomalies).
3. Open the **Anomaly Inbox** for flagged runs; read each anomaly's explanation + evidence.
4. Export to your backend if you need long-term retention or sharing.
